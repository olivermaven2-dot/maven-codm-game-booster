# Maven CODM Booster

A lightweight Android companion project focused on preparing a Samsung Galaxy A04e for Call of Duty: Mobile.

## Project goals

- Keep the app lightweight for devices with 3 GB RAM.
- Provide a simple gaming dashboard and CODM setup guidance.
- Show Android system information only where the OS permits it.
- Offer safe, transparent optimization steps without root access.
- Never claim to increase FPS, alter touch sampling, or control CPU/GPU performance when Android does not expose those capabilities.

## Build

This is a native Android project using Kotlin and Gradle. Open the repository in Android Studio or build the debug APK with the included GitHub Actions workflow.

## Device target

- Samsung Galaxy A04e
- Android version depends on the device's installed system software
- 32 GB storage / 3 GB physical RAM

## Important limitations

Android apps cannot freely terminate other apps, clear another app's private data, force CPU/GPU clocks, or guarantee lower ping. This project will use supported Android APIs and clear user-facing guidance instead.
